Robust Aggregation for Federated Learning

更新于 2024.11.18

为什么我们要更新算法，因为FedAvg并不鲁棒

Robustness: We would like a federated learning algorithm to be robust to corrupted updates contributed by malicious devices or hardware/software failures. FedAvg uses an arithmetic mean to aggregate the device updates in (3), which is known to not be robust [34]. This can be made precise by the notion of a breakdown point [67], which is the smallest fraction of the points which need to be changed to cause the aggregate to take on arbitrary values. The breakdown point of the mean is 0, since only one point needs to changed to arbitrarily change the aggregate [10]. This means in federated learning that a single corrupted update, either due to an adversarial attack or a failure, can arbitrarily change the resulting aggregate in each round. 然而，事实证明，健壮性与联合学习的另外两个特性并不直接兼容，即通信效率和隐私。

联邦学习通常通过安全多方计算（Secure Multi-Party Computation, SMPC）实现隐私保护。在此机制下，设备端的更新会被加密或添加噪声，服务器无法直接看到单个设备的贡献。

现有方法，分布式优化和拜占庭鲁棒性

现有的鲁棒方法（如多Krum、修剪平均） 对异常更新的处理性能较好，但通常无法在 隐私保护的情况下有效实施。

几何中位数是多维数据的一种鲁棒中心估计方法，对超过50%的点被污染仍具有强鲁棒性。

Weiszfeld算法是经典的几何中位数求解算法但其在数值上不稳定，需进一步改进。

作者定义了设备可能遭遇的三种污染情况： • 数据污染：设备本地数据被篡改（如标签翻转或数据变形）。 • 更新污染：设备返回的更新被注入噪声或恶意操控。 • 自适应污染：恶意设备基于全局模型生成对抗性更新。

迭代安全聚合（iterative secure aggregate）

  1. Static data poisoning: The corrupted devices C are allowed to modify their training data prior to the start of the training, and the data is fixed thereafter. Formally, the objective function of device i ∈ C is now F ̃i(w) = Ez∼D ̃i [f (w; z)] where D ̃i has been modified from the original Di. These devices then participate in the local updates (2) with ∇F ̃i rather than ∇Fi. We consider device i to contribute corrupted updates only if D ̃i ∈/ D (for instance, D is the set of natural RGB images). b) Adaptive data poisoning: The corrupted devices C are allowed to modify their training data in each round of training depending on the current model w(t). Concretely, the objective function of device i ∈ C in round t is F ̃(t) i (w) = Ez∼D ̃ (t) i [f (w; z)] where D ̃ (t) i has been modified from the original Di using knowledge of w(t). As previously, these devices then participate in the local updates (2) with ∇F ̃(t) i rather than ∇Fi in round t. c) Update Poisoning: The corrupted devices can send an arbitrary vector to the server for aggregation, as described by (4) in its full generality. This setting subsumes all previous examples as special cases. 三种不同的损坏

I. 引言

•   背景：
•   联邦学习通过分布式设备协作训练模型，保护数据隐私。
•   当前主流方法FedAvg对异常值敏感，缺乏鲁棒性，尤其在设备更新被污染的情况下。
•   动机：
•   提出一种基于几何中位数的鲁棒聚合方法RFA，能在高污染场景中有效工作。
•   贡献：
1.  将几何中位数引入联邦学习，设计了鲁棒的聚合算法。
2.  提供了理论分析，证明了算法的收敛性和鲁棒性。
3.  实验表明，RFA在高污染场景下的性能远优于传统方法。

  1. 相关工作

    • 联邦学习：以隐私保护为核心的分布式优化方法，FedAvg是其代表算法。 • 鲁棒估计：几何中位数作为经典的鲁棒统计方法，能抵抗高达50%的异常值。 • 对抗性更新：现有方法如Multi-Krum、Trimmed Mean关注拜占庭鲁棒性，但通信效率和隐私保护兼顾不足。 • 研究目标： • 结合几何中位数的鲁棒性与联邦学习的隐私保护需求，设计高效的聚合方法。

  2. 问题设定

•   联邦学习框架：
•   在 ￼ 个设备中，每个设备 ￼ 使用本地数据分布 ￼ 训练局部模型 ￼，服务器聚合得到全局模型 ￼。
•   FedAvg使用算术平均聚合，敏感于异常值。
•   污染模型：
1.  静态数据污染：设备本地数据在训练前被修改。
2.  自适应数据污染：设备根据全局模型动态生成对抗性数据。
3.  更新污染：设备提交伪造的更新向量。
•   目标：

设计一种鲁棒的联邦学习方法，在设备更新被污染时，依然能够收敛到高质量的全局模型。

  1. 鲁棒聚合与RFA算法

本章重点：介绍RFA方法的设计原理、核心算法及其理论鲁棒性。

  1. 几何中位数聚合

    • 定义： 几何中位数 ￼ 是最小化加权欧几里得距离和的点： ￼ • ￼：设备更新。 • ￼：设备的权重。 • 鲁棒性： • 几何中位数具有断点 ￼，即使50%的设备被污染，仍能保证结果的稳定性。 • 相比算术平均（断点为0），几何中位数对异常值具有显著的鲁棒性。

  1. 理论分析

    • 鲁棒性：在最多50%的设备被污染时，RFA仍能稳定收敛。 • 误差来源：

    1. 几何中位数的近似误差（由迭代算法引入）。
    2. 数据异质性误差（设备数据分布差异）。 • 收敛性： • 在强凸优化问题中，RFA具有线性收敛特性，最终误差由随机噪声、数据异质性和几何中位数误差决定。

V. 实验

•   数据集与任务：
1.  EMNIST（字符识别）
2.  Shakespeare（字符级语言建模）
3.  Sent140（情感分析）
•   实验结果：
•   鲁棒性：
•   在静态数据污染、自适应数据污染和更新污染下，RFA准确率远高于FedAvg。
•   对全知更新污染，RFA仍表现出显著的抗干扰能力。
•   通信效率：
•   RFA通信成本约为FedAvg的3-5倍，但在高污染场景下，额外开销是可以接受的。
•   个性化扩展：
•   个性化RFA在异质数据分布场景下表现更佳，准确率提升5%-10%。

  1. 结论

    • 主要贡献： • 提出一种鲁棒联邦聚合方法（RFA），结合几何中位数实现对设备更新污染的鲁棒性。 • 理论与实验均表明，RFA在高污染场景下显著优于传统方法。 • 局限性： • 通信成本较高。 • 对极端对抗性攻击（如拜占庭攻击）仍需额外机制支持。 • 未来方向：

    1. 提升几何中位数计算效率。
    2. 扩展至更复杂的深度学习任务。
    3. 研究动态设备参与场景下的鲁棒性。

总结

这篇论文通过将几何中位数引入联邦学习，设计了一种兼具鲁棒性和隐私保护的聚合方法。RFA方法在理论和实验中均表现出优越性，是联邦学习领域的一项重要进展。
